# Dinesh Thumma — Engineering Portfolio

A minimalist, high-performance developer portfolio built with [Astro](https://astro.build) and [Tailwind CSS v4](https://tailwindcss.com). Features zero client-side JavaScript, sub-millisecond static page rendering, and an engineering-first design.

---

## ⚡ Tech Stack & Architecture

- **Framework**: [Astro 5](https://astro.build) (Static Site Generation / SSG, 0 KB client JS runtime)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com) (Utility-first CSS, dark-mode first)
- **Language**: TypeScript
- **Deployment**: Static HTML output ready for Vercel, Cloudflare Pages, or GitHub Pages
